配置此浏览器的自动保存

此设置只用于首次连接或迁移浏览器，日常打开作战表无需填写。

  1. 已有连接：在原浏览器的本设置页复制连接，在新浏览器粘贴。
  2. 新建连接：前往 GitHub 专用令牌设置，仅选择 tumytime.github.io，添加 Contents 读写权限。

令牌只保存在你选择的浏览器，不会写入仓库。新计划和自建任务保存在 kaoyan/logs/planner-v3.json；旧日志继续保留。
